**Una herramienta ligera y rápida para convertir contenido de YouTube a formatos locales como mp3/mp4 con metadatos/album para su organizacion en reproductores.**

# Características

###  **Descarga Inteligente**
- **MP3 alta calidad**: VBR ~190-250kbps con metadatos ID3
- **MP4 múltiples resoluciones**: 144p a 1080p
- **Detección automática** de videos "Auto-generated by YouTube"
-  **Extracción de metadatos** (canción, artista, álbum, año)
-  **Thumbnails HD** incluidos en archivos MP3

###  **Metadatos Avanzados**
```
# Detecta automáticamente:
Título: "Full Moon Full Life"
Artistas: ["Azumi Takahashi", "Lotus Juice"]
Álbum: "Persona 3 Reload Original Soundtrack"
Año: "2024"
Sello: "NexTone Inc." 
```


###  Interfaces Multiplataforma 

- **CLI avanzada**: Comandos rápidos tipo `ndxyt mp3 <URL>`
- **Diálogos “Guardar como”**: Nativos para Windows y Linux

- **Web App**: Pensada para uso Gui/Mobile
- **Selección de calidad**: 7 niveles de calidad de video

###  Optimizaciones Técnicas
- **Prioriza itag 251** (Opus 160 kbps) para música
- **Streams DASH** para máxima calidad de video
- **Conversión FFmpeg** con parámetros optimizados
- **Manejo de errores robusto** con reintentos automáticos


# Instalación

### Instalar FFmpeg REQUERIDO! para su uso!

**¿Que es FFmpeg?**  
FFmpeg es una suite completa, gratuita y open-source para manipular audio y video. Es como un "Photoshop" para archivos multimedia, pero en la línea de comandos.  
Este proyecto hace uso de esta herramienta externa, por lo que se pide su instalacion por mejor comodidad y uso.

| Sistema | Comando |
|--------|--------|
| **Windows** | `winget install ffmpeg` <br> |
| **Linux (Debian/Ubuntu)** | `sudo apt install ffmpeg` |

Si deseas hacer descarga de FFmpeg manual desde su sitio oficial:  
    https://ffmpeg.org/download.html

###  Opciones Avanzadas

```bash

mp3 <URL> --no-dialog o -n

# Especificar ruta de salida personalizada

# Usar calidad específica

mp4 <URL> -q 4   # 480p
````

##  Calidades Disponibles

| Código | Resolución | Descripción | Uso Recomendado |
|------:|-----------|------------|----------------|
| 1 | 144p | Calidad baja | Videos cortos, ancho de banda limitado |
| 2 | 240p | Media-baja |  Compromiso calidad / tamaño |
| 3 | 360p | Estándar | Uso general, móviles pequeños |
| 4 | 480p | DVD Calidad | Pantallas medianas |
| 5 | 720p | HD | RECOMENDADO – Mejor relación calidad / tamaño |
| 6 | 1080p | Full HD | Pantallas grandes, máxima claridad |
| 7 | Máxima | Mejor disponible | Calidad original del video |

###  Endpoints de la API

| Método | Endpoint | Descripción |
|--------|----------|-------------|
| `GET` | `/` | **Index** - Página principal de la aplicación |
| `GET` | `/request` | **Obtener Info Video** - Extrae metadatos de un video de YouTube |
| `GET` | `/conversion/mp3` | **Convertir Mp3** - Descarga video como archivo MP3 |
| `GET` | `/conversion/mp4` | **Convertir Mp4** - Descarga video como archivo MP4 con calidad seleccionable |
| `POST` | `/debug/streams` | **Debug Streams** - Lista streams disponibles para depuración |

---

###  Detalles por Endpoint

#### `GET /`
**Nombre:** Index  
**Propósito:** Página de inicio de la Web UI  
**Respuesta:** HTML con interfaz gráfica  

#### `GET /request`
**Nombre:** Obtener Info Video  
**Parámetro:** `urlVideo` (string) - URL del video  
**Respuesta:** JSON con metadatos del video  

#### `GET /conversion/mp3`
**Nombre:** Convertir Mp3  
**Parámetro:** `url` (string) - URL del video  
**Respuesta:** Archivo MP3 descargable  

#### `GET /conversion/mp4`
**Nombre:** Convertir Mp4  
**Parámetros:**
- `url` (string) - URL del video
- `calidad` (int) - Nivel de calidad (1-6)  
**Respuesta:** Archivo MP4 descargable  

#### `POST /debug/streams`
**Nombre:** Debug Streams  
**Parámetro:** `url` (string) - URL del video  
**Respuesta:** JSON con información de depuración  
**Uso:** Exclusivo para desarrollo y troubleshooting
