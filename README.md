**Una herramienta ligera y rápida para convertir contenido de YouTube a formatos locales como mp3/mp4 con metadatos/album para su organizacion en reproductores.**

# Características

###  **Descarga Inteligente**
- **MP3 alta calidad**: VBR ~190-250kbps con metadatos ID3
- **MP4 múltiples resoluciones**: 144p a 1080p
- **Detección automática** de videos "Auto-generated by YouTube"
-  **Extracción de metadatos** (canción, artista, álbum, año)
-  **Thumbnails HD** incluidos en archivos MP3

###  **Metadatos Avanzados**
```
# Detecta automáticamente:
Título: "Full Moon Full Life"
Artistas: ["Azumi Takahashi", "Lotus Juice"]
Álbum: "Persona 3 Reload Original Soundtrack"
Año: "2024"
Sello: "NexTone Inc." 
```


###  Interfaces Multiplataforma 

- **CLI**: Comandos rápidos tipo `ndxYtConv mp3 <URL>`

- **Web App**: Pensada para uso Gui/Mobile
- **Selección de calidad**: 7 niveles de calidad de video

###  Optimizaciones Técnicas
- **Prioriza itag 251** (Opus 160 kbps) para música
- **Streams DASH** para máxima calidad de video
- **Conversión FFmpeg** con parámetros optimizados
- **Manejo de errores robusto** con reintentos automáticos



# Instalación

## 1. Requisito: FFmpeg (obligatorio)

FFmpeg es una herramienta externa que usa el proyecto para convertir audio y video. Sin ella, las conversiones fallan.

| Sistema | Comando |
|--------|--------|
| **Windows** | `winget install Gyan.FFmpeg` |
| **Linux (Debian/Ubuntu)** | `sudo apt install ffmpeg` |

Cierra y abre la terminal después de instalarlo y comprueba que funciona con `ffmpeg -version`.
Descarga manual: https://ffmpeg.org/download.html

## 2. Instalar la aplicación (recomendado: pipx)

[pipx](https://pipx.pypa.io) instala el programa en su propio entorno aislado y deja los comandos disponibles desde cualquier terminal, sin activar nada. En Linux moderno también evita el error `externally-managed-environment` de pip.

### Windows

```powershell
# 1. Instalar pipx (una sola vez, fuera de cualquier venv)
python -m pip install --user pipx
python -m pipx ensurepath

# 2. Cerrar y abrir la terminal

# 3. Clonar e instalar
git clone https://github.com/jimrobert796/NdxYtConv.git
cd NdxYtConv
pipx install .
```

### Linux (Debian/Ubuntu)

```bash
# 1. Instalar pipx (una sola vez)
sudo apt install pipx
pipx ensurepath

# 2. Cerrar y abrir la terminal

# 3. Clonar e instalar
git clone https://github.com/jimrobert796/NdxYtConv.git
cd NdxYtConv
pipx install .
```

### Comprobar la instalación

```bash
ndxytconv --help
```

> Los comandos van en **minúsculas**: `ndxytconv` y `ndxytconv-web`. En Linux distinguen mayúsculas.

### Actualizar, reinstalar y desinstalar

```bash
pipx upgrade ndxYtConv        # actualizar dependencias (útil si YouTube cambia algo)
pipx install . --force        # reinstalar tras cambiar el código o el setup.py
pipx uninstall ndxYtConv      # desinstalar
```

Para desarrollo, instala con `pipx install -e .` (modo editable) y tus cambios se reflejan sin reinstalar.

### Ejecutable compilado (Windows)

1. Descarga el archivo ZIP `NdxYtConver Winver-x64.zip`
2. Descomprime el contenido
3. Ejecuta `NdxYtConver.exe`

## Solución de problemas

| Problema | Solución |
|---------|----------|
| `pipx` o `ndxytconv` no se reconoce | Cierra y abre la terminal. Si sigue, ejecuta `python -m pipx ensurepath` y ábrela de nuevo |
| Linux: el comando no se encuentra | `export PATH="$HOME/.local/bin:$PATH"` (agrégalo a tu `~/.bashrc`) |
| Linux: `externally-managed-environment` | No uses `pip install` global; usa pipx o un venv |
| `ffmpeg` no encontrado | Instálalo (paso 1) y reabre la terminal |
| Error "detected as a bot" de YouTube | Actualiza: `pipx upgrade ndxYtConv` |
| PowerShell no deja activar el venv | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` |

# Instalación para desarrollo

### Con entorno virtual (.venv)

```bash
# 1. Clonar el repositorio
git clone https://github.com/jimrobert796/NdxYtConv.git
cd NdxYtConv

# 2. Crear el entorno virtual
python -m venv .venv

# 3. Activarlo
.venv\Scripts\activate          # Windows
source .venv/bin/activate       # Linux

# 4. Actualizar pip e instalar en modo editable
python -m pip install --upgrade pip
pip install -e .

# 5. Ejecutar (con el venv activado)
ndxytconv-web
```

Las herramientas de empaquetado (PyInstaller) se instalan aparte: `pip install -r requirements.txt`.

### Docker

```bash
git clone https://github.com/jimrobert796/NdxYtConv.git
cd NdxYtConv

docker build -t ndxytconv .
docker run -d -p 8000:8000 --name fastapi_ndxytconv ndxytconv
```

### Docker Compose (recomendado)

```bash
git clone https://github.com/jimrobert796/NdxYtConv.git
cd NdxYtConv

docker compose up -d --build   # construir y ejecutar
docker compose logs -f         # ver logs
docker compose down            # detener
```

FFmpeg se instala automáticamente dentro de la imagen. La web queda en http://localhost:8000.

###  Ejemplos de uso

#### Descarga e conversion a .mp3
```bash
mp3 https://youtu.be/dQw4w9WgXcQ
```

#### Descarga e conversion a .mp4
```bash
mp4 https://youtu.be/dQw4w9WgXcQ
```

#### Consulta de url
```bash
info https://youtu.be/dQw4w9WgXcQ
```

#### Debug streams
```bash
streams https://youtu.be/dQw4w9WgXcQ
```

#### Especificar ruta de salida personalizada
```bash
# .mp4
mp4 https://youtu.be/dQw4w9WgXcQ -o "C:/Videos/video.mp4"

# .mp3
mp3 https://youtu.be/dQw4w9WgXcQ -o "C:/Music/music.mp3"
````

#### Usar calidad específica
```bash
mp4 https://youtu.be/dQw4w9WgXcQ -q 2   # 240p
mp4 https://youtu.be/dQw4w9WgXcQ -q 5   # 720p
````

##  Calidades Disponibles

| Código | Resolución | Descripción | Uso Recomendado |
|------:|-----------|------------|----------------|
| 1 | 144p | Calidad baja | Videos cortos, ancho de banda limitado |
| 2 | 240p | Media-baja |  Compromiso calidad / tamaño |
| 3 | 360p | Estándar | Uso general, móviles pequeños |
| 4 | 480p | DVD Calidad | Pantallas medianas |
| 5 | 720p | HD | RECOMENDADO – Mejor relación calidad / tamaño |
| 6 | 1080p | Full HD | Pantallas grandes, máxima claridad |
| 7 | Máxima | Mejor disponible | Calidad original del video |

# Dependencias del proyecto

A continuación se describen las dependencias utilizadas en **NdxYtConver** y su propósito dentro del proyecto.

###  Backend & API

- **fastapi (0.127.0)**  
  Framework principal para la creación de la API y la Web UI.

- **uvicorn (0.40.0)**  
  Servidor ASGI utilizado para ejecutar la aplicación FastAPI.



###  Plantillas & Formularios

- **Jinja2 (3.1.6)**  
  Motor de plantillas HTML utilizado para renderizar la interfaz web.

- **python-multipart (0.0.21)**  
  Manejo de formularios y subida de archivos mediante `multipart/form-data`.


###  Descarga & Procesamiento Multimedia

- **pytubefix (11.2.2)**  
  Descarga de audio y video desde YouTube.

- **mutagen (1.47.0)**  
  Escritura y edición de metadatos en archivos MP3 y MP4.

- **python-dateutil (2.9.0.post0)**  
  Manejo avanzado de fechas y duración de contenido multimedia.  

- **FFmpeg (externo)**   
Herramienta externa **obligatoria** utilizada para:
  - `Conversión de audio y video`
  - `Extracción de audio desde video`
  - `Combinación de streams (audio + video)`


###  Utilidades de Red

- **requests (2.32.3)**  
  Cliente HTTP para realizar peticiones externas y validaciones.


###  Tipado & Compatibilidad

- **typing_extensions (4.14.1)**  
  Extensiones de tipado para compatibilidad entre versiones de Python.


###  Empaquetado & Distribución

- **pyinstaller (6.18.0)**  
  Empaquetado del proyecto en ejecutables portables para Windows.


##  Notas

- Las dependencias de empaquetado solo se utilizan durante el proceso de build.
- FFmpeg se gestiona como  externo para garantizar compatibilidad multiplataforma.



###  Endpoints de la API

| Método | Endpoint | Descripción |
|--------|----------|-------------|
| `GET` | `/` | **Index** - Página principal de la aplicación |
| `GET` | `/request` | **Obtener Info Video** - Extrae metadatos de un video de YouTube |
| `GET` | `/conversion/mp3` | **Convertir Mp3** - Descarga video como archivo MP3 |
| `GET` | `/conversion/mp4` | **Convertir Mp4** - Descarga video como archivo MP4 con calidad seleccionable |
| `POST` | `/debug/streams` | **Debug Streams** - Lista streams disponibles para depuración |

---

###  Detalles por Endpoint

#### `GET /`
**Nombre:** Index  
**Propósito:** Página de inicio de la Web UI  
**Respuesta:** HTML con interfaz gráfica  

#### `GET /request`
**Nombre:** Obtener Info Video  
**Parámetro:** `urlVideo` (string) - URL del video  
**Respuesta:** JSON con metadatos del video  

#### `GET /conversion/mp3`
**Nombre:** Convertir Mp3  
**Parámetro:** `url` (string) - URL del video  
**Respuesta:** Archivo MP3 descargable  

#### `GET /conversion/mp4`
**Nombre:** Convertir Mp4  
**Parámetros:**
- `url` (string) - URL del video
- `calidad` (int) - Nivel de calidad (1-6)  
**Respuesta:** Archivo MP4 descargable  

#### `POST /debug/streams`
**Nombre:** Debug Streams  
**Parámetro:** `url` (string) - URL del video  
**Respuesta:** JSON con información de depuración  
**Uso:** Exclusivo para desarrollo y troubleshooting
